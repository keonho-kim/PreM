# PreM UI 목업

브라우저에서 제품 흐름과 슬라이드 편집을 확인하는 독립적인 HTML/CSS/JavaScript 애플리케이션이다. 프레임워크·빌드·DB·업무 서버 없이 실행한다.

## 실행

저장소 루트에서:

```sh
python3 mock/helpers/serve.py
```

- Home: `http://127.0.0.1:5174/`
- 편집기: `http://127.0.0.1:5174/#view=editor&project=platform&deck=deck1`
- 직접 열기: `mock/index.html`

## 기능과 범위

프로젝트·가이드·목차·샘플 근거·템플릿 탐색, Space 등록 흐름, 샘플 생성, 슬라이드 직접 편집, 선택 기반 AI 대화와 JSON 내보내기를 제공한다.

원본 문서와 Space 업로드는 파일명·크기만 사용한다. 캔버스에 명시적으로 삽입한 이미지는 메모리에서 읽는다. 상태는 새로고침하면 초기화된다. 실제 AI 호출·문서 변환·OCR·PPTX 저장·서버 인증은 제공하지 않는다.

## 소스와 산출물

`index.html`은 deferred script를 순서대로 등록하고 `app.js`가 상태와 기능을 조립한다. `js/`는 기능과 DOM 어댑터, `styles.css`와 `styles/`는 스타일을 담당한다. 공통 색상은 `../design/refract.tokens.json`에서 생성한다.

로컬 폰트와 라이선스는 `assets/`, Lucide 아이콘 사전은 `icons.js`와 `editor-icons.js`에 있다. 보조 도구는 `helpers/`, 임시 검증 출력은 `helpers/.artifacts/`, 화면 캡처는 `captures/folio/`에 둔다. 목업은 `../data/`에 상태나 검증 자료를 저장하지 않는다.

## 프로젝트 갤러리

Home은 데스크톱 3열 카드, 중간 화면 2열, 휴대폰 1열로 표시한다. 한 페이지는 6개 프로젝트다. 카드에는 PPT 미리보기 또는 미생성 상태, 프로젝트명·상태·문서/PPT 수·가이드 버전·종료일·D-Day·최근 수정일을 보여준다.

프로젝트 등록 폼에서 종료일을 필수로 입력하며 native 달력으로 선택한다. 카드의 날짜는 읽기 전용이다. 종료일 기간 필터는 별도의 검색 조건이며 양 끝 날짜를 포함한다. 이름 검색과 정렬·상태 필터를 바꾸면 첫 페이지로 돌아간다.

카드 우클릭 또는 점 세 개 버튼은 같은 메뉴를 연다. 이름 바꾸기, 복제, 보관/복원, 삭제를 제공하고 삭제는 프로젝트명을 보여주는 확인 창을 거친다. 삭제는 해당 프로젝트의 목업 상태와 작업만 제거하며 진행 중인 샘플 생성도 취소한다. 마지막 프로젝트를 삭제해도 새 프로젝트를 등록할 수 있다.

종료일은 시간대 없는 `YYYY-MM-DD`로 저장한다. D-Day는 브라우저의 현지 날짜 기준이고, 오늘은 `D-Day`, 미래는 `D-n`, 지난 날짜는 `D+n`이다. 자정과 화면 복귀 시 갱신한다. 실제 제품 API·SQLite에는 이 목업의 종료일·삭제 기능이 아직 반영되지 않았다.

프로젝트 생성은 Home 상단 버튼에서 시작한다. 갤러리 빈 공간·카드의 새 프로젝트 메뉴도 같은 필수 마감일 폼을 연다. 우측 하단은 진행 패널과 토스트에 사용한다.

`js/feedback.js`는 페이지 수명의 작업 패널·토스트를 소유하고 `js/app-events.js`가 전역 이벤트를 연결한다. Space 등록 자료와 이 탭에서 시작한 샘플 생성만 작업 패널에 표시한다. 다른 샘플 자산은 작업으로 만들지 않는다. 타이머·토스트·관찰자는 초기화/페이지 종료 때 정리하며 실제 파일 전송은 하지 않는다. 검증: `node mock/helpers/work-feedback.cjs`.

## Space 미리보기

Space의 자료 이름을 누르면 템플릿 장표 또는 레퍼런스 내용을 미리본다. 템플릿은 큰 장표·선택 가능한 썸네일·이전/다음 탐색을 제공하며 Studio의 템플릿 미리보기에서도 같은 화면을 사용한다. 구조 목록·슬롯 검증·체크포인트는 표시하지 않는다. 업로드한 파일은 읽지 않으며 샘플 디자인에는 실제 업로드 결과가 아니라는 안내를 표시한다.

`js/asset-preview.js`는 `space.js`보다 먼저 등록한다. 선택 상태는 미리보기 모듈이, 대화 상자 초점·닫기는 기존 native dialog가, 장표 크기 조정은 기존 ui 모듈이 담당한다. 제품 API와 연결되지 않는다.

## 일반 사무직 사용자 경험

목업의 주 사용자는 일반 사무직이다. 분기 보고·회의 준비를 샘플로 사용하며, 문서·미리보기·다음 행동을 중심으로 화면을 구성한다. 내부 실행 구조·판정·저장 로직은 표시하지 않고 이전 내용과 연결 상세만 필요할 때 펼친다. 상단의 샘플 체험 표시와 파일 전송·AI·발표 파일 생성의 제한 안내는 유지한다.
