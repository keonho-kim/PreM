# 슬라이드 편집과 AI 대화

제품은 실제 PPTX 생성과 **현재 슬라이드의 제목·본문·발표 메모를 대화로 수정하는 기능**을 제공한다. 아래에서 별도로 표시한 캔버스 객체 조작은 HTML 목업 범위다. 생성된 PPTX의 텍스트와 도형은 PowerPoint에서 편집할 수 있다.

## 제품 대화 수정

Studio → 생성·편집 → 우측 **AI와 대화**에서 작성 AI와 수정 범위(현재 슬라이드/제목만/본문만/발표 메모만)를 선택하고 요청한다. 메시지와 수정 전후를 검토한 뒤 **수정안 적용**을 누르면 새 PPTX 리비전을 만든다. 제안 도착만으로 원본을 변경하지 않는다. 실패·취소·재시도와 수정안 버리기를 지원한다.

- `features/presentations/slide-chat.tsx`는 Query 기반 메시지 조회·명령, `chat-drafts.ts`는 프로젝트/리비전/슬라이드별 메모리 draft를 소유한다. 공식 shadcn Message/Bubble/Message Scroller와 InputGroup을 사용한다. Enter 전송은 IME 조합을 제외하고 Shift+Enter는 줄바꿈한다.
- Rust `modules/presentations/edits.rs`는 입력·취소·lease·고정 모델 실행, `edit_model.rs`는 `propose_slide_patch` 형식과 허용 필드 검증, SQLite `presentations/edits/`는 접수·체크포인트·조건부 적용을 소유한다.
- 기존 native Provider adapter와 모델 실행 한도/이력을 재사용한다. 이는 제한된 구조화 수정 명령이며 Provider-native 다중 Tool Calling이나 임의 도구 실행 에이전트는 아니다. 메시지는 토큰 스트리밍 대신 영속 작업 조회로 갱신한다.
- 서버는 선택하지 않은 필드·근거 ID를 원본에서 보존한다. 적용 직전 최신 deck version을 검사하고 오래된 수정안은 거부한다. 변경한 SlideSpec만 새 Blob/slide version으로 저장하며 다른 장표의 version은 재사용한다. 출력 PPTX 조립·미리보기·Kordoc 검증은 전체 deck에 수행한다.
- 대화 이력은 공유 프로젝트의 SQLite에 저장된다. draft는 브라우저 메모리만 사용하며 최대 128개 범위를 보관한다. 이전 리비전은 읽기 전용이며 적용이 끝난 최신 리비전에서 계속 수정한다. 패널을 접어도 입력과 선택을 유지한다.

이미지·차트 삽입, 객체별 캔버스 선택/다중 선택, 레이아웃 수정, 여러 장표 일괄 편집은 제품에 아직 연결되지 않았다. 아래 목업 기능을 이 실제 구현 범위와 혼동하지 않는다.

## 목업 작업 영역

편집기는 좌측 슬라이드 목록, 중앙 캔버스, 우측 AI 대화·Reference 탭으로 구성된다. 좌우 패널은 외부의 펼침·접힘 버튼으로 독립적으로 숨긴다. 패널 DOM을 유지하므로 접기와 탭 전환만으로 작성 중 메시지가 사라지지 않는다.

폰에서는 슬라이드 목록이 캔버스 위의 가로 목록이 되고, 인스펙터는 아래에 배치된다. Studio 제작 진도는 편집기에서도 항상 펼쳐 표시하며 전역 메뉴 아래에 고정한다. 좌우 작업 패널만 독립적으로 접을 수 있다.

## 슬라이드 조작

- 목록 헤더의 `+`는 현재 슬라이드 뒤에 새 장표를 만든다.
- 썸네일 우클릭, 더보기 또는 Shift+F10으로 메뉴를 연다. 복제·삭제·아래 삽입과 앞뒤 이동을 제공한다.
- 슬라이드 사이와 빈 공간에 삽입선을 표시하고, 그 위치의 우클릭 메뉴에서 새 장표를 삽입한다.
- 드래그 핸들로 순서를 바꾼다. 이동 중에는 삽입 위치를 표시하고 drop에서 한 번 확정한다. Escape와 포인터 취소는 순서 변경을 취소한다.
- Alt+방향키로 순서를 바꿀 수 있다. 마지막 한 장은 삭제하지 않는다.

## 요소 선택

| 입력                                          | 결과                                    |
| --------------------------------------------- | --------------------------------------- |
| 제목·본문 또는 삽입 객체 일반 클릭            | 단일 요소 선택                          |
| Ctrl+클릭 / macOS ⌘+클릭                      | 해당 요소를 선택 집합에 추가하거나 제거 |
| 캔버스 빈 공간 클릭 / 대화 입력창의 선택 해제 | 요소 선택 해제, 현재 슬라이드 범위 표시 |
| 다른 슬라이드·deck으로 이동                   | 선택 집합 초기화                        |
| 채팅 입력창·Reference 탭으로 이동             | 같은 슬라이드의 선택 유지               |

선택 키는 `field:title`, `field:{bodyIndex}`, `object:{objectId}`다. 본문 키는 배열 위치에 종속되므로 영속 도메인의 컴포넌트 ID로 사용하기에 충분하지 않다.

**다중 선택은 AI 대화의 수정 범위를 지정한다.** 그룹 이동·크기 변경·그룹화·다중 객체 도구 일괄 적용은 구현되지 않았다. 캔버스의 장식·차트 샘플 전체가 독립 편집 객체로 구성된 것도 아니다.

| 객체 이동·크기        | 포인터 드래그·모서리, 방향키 이동·Alt+방향키 크기 변경 |

| 레이어                | 삽입 객체를 맨 앞·맨 뒤로 이동                         |
| 화면 배율             | 50~200%, 25% 단위, 100% 맞춤                           |

좌표 기준은 960×540이다. 삽입 객체의 위치·크기는 이 영역 안으로 제한하고 최소 크기는 24다. 제목 직접 입력은 100자, 일반 텍스트 입력은 최대 2,000자로 제한한다. 텍스트 일부 구간만 선택해 서식을 지정하는 rich text run은 지원하지 않는다.

이미지는 최대 2 MiB, 1,600만 화소다. 사용자가 선택한 이미지에 한해 내용을 읽고 data URL로 메모리에 보관한다. 이미지 처리가 끝나기 전에 화면·리비전이 바뀌면 삽입하지 않는다. 외부 URL을 가져오지 않는다.

## 목업 AI 대화

우측 AI 탭에는 메시지 이력과 하단 입력창을 둔다. 입력창 위에 선택한 요소 또는 현재 슬라이드를 표시한다. Enter는 전송, Shift+Enter는 줄바꿈이다. 한글 조합 확정 Enter는 `isComposing`과 `keyCode === 229` 검사로 전송에서 제외한다.

대화는 deck 객체를 키로 하는 WeakMap과 slide ID별 Map에 보관한다. 메시지와 draft는 슬라이드 이동 후에도 복원되며 다른 프로젝트·deck과 공유되지 않는다. 새로고침하면 모두 초기화된다.

### 수정안 처리

1. 전송 시 선택 키와 대상 slide, 현재 deck version을 읽는다.
2. 사용자의 메시지를 추가하고 해당 범위의 수정안을 계산한다.
3. 변경 전후를 대화 안에 표시한다. 아직 원본 슬라이드는 바뀌지 않는다.
4. 적용 시 현재 slide와 deck version이 요청 당시와 같은지 확인한다.
5. 일치하면 해당 슬라이드를 새 상태로 commit한다. 다른 요소·슬라이드와 기존 deck 리비전은 유지한다.
6. 리비전이 달라졌다면 적용을 거부하고 다시 요청하도록 안내한다. 선택만 바뀐 경우에는 원래 수정 대상이 유지된다.

검사는 deck 전체 version을 사용하므로 같은 deck의 다른 변경도 수정안을 무효화할 수 있다. 이는 브라우저 단일 세션의 충돌 방어이며 서버 낙관적 동시성 제어가 아니다.

### 규칙 기반 응답

| 요청                             | 계산 방식                                 |
| -------------------------------- | ----------------------------------------- |
| 따옴표로 감싼 문구               | 선택한 텍스트 값을 해당 문구로 치환       |
| 짧게·요약·간결                   | 24자보다 긴 텍스트를 자르고 말줄임표 추가 |
| 굵게·기울임                      | 선택한 텍스트 요소의 서식 설정            |
| 크게·작게                        | 삽입 객체 크기를 1.1배·0.9배로 변경       |
| 오른쪽·왼쪽·위로·아래로          | 삽입 객체를 해당 방향으로 20 이동         |
| 적용할 규칙이 없거나 변화가 없음 | 상태 변경 없이 지원 요청 안내             |

선택이 없을 때 따옴표 또는 제목 요청은 제목을, 그 밖의 요청은 본문 필드를 대상으로 계산한다. 일부 선택 요소에만 적용 가능한 요청은 변경 수와 나머지 수를 안내한다. 이는 언어 이해·의미 요약·이미지 생성 기능이 아니다.

## 목업 리비전과 실행 취소

편집 commit은 기존 슬라이드 상태를 undo에 기록하고 redo를 비운 뒤 deck version을 증가시킨다. deck 리비전에는 전체 슬라이드 스냅샷을 추가한다. undo 스택은 최대 20단계다.

실행 취소·다시 실행·리비전 복원도 deck에 새 리비전을 추가한다. 과거 기록을 삭제하거나 deck version을 되돌리지 않는다. 다만 복원된 슬라이드의 `version` 값은 스냅샷 값을 따른다. 현재 `slide.version`은 전역 단조 증가 영속 식별자가 아니다.

## 목업 Reference와 내보내기

Reference 탭은 현재 슬라이드의 샘플 근거에 연결된 시각 자료를 제공한다. 자료를 선택하면 해당 슬라이드의 `sourceInsertions`에 원본·버전·방식이 포함된 계획을 새 리비전으로 저장한다. 채팅의 요소 선택과 별도 상태다.

내보내기는 슬라이드 내용·서식·객체·이미지 data URL을 포함한 JSON이다. 실제 PPTX 생성, PowerPoint/Keynote 호환, 차트 원본 편집, 이미지 자르기·회전, 애니메이션과 공동 편집은 구현되지 않았다.
