# 슬라이드 편집과 AI 대화

제품은 실제 PPTX 생성과 **선택한 장표의 텍스트·이미지·차트·도형·배치를 대화로 수정하는 기능**을 제공한다. 생성된 PPTX의 텍스트와 도형은 PowerPoint에서 편집할 수 있다.

## 제품 대화 수정

중앙 도구막대의 확대 버튼 왼쪽에 **전/후 비교**와 **되돌리기** 아이콘을 둔다. 비교 아이콘을 누르는 동안 이전 장표를 표시하고 놓으면 현재 장표로 돌아온다. 마우스·터치와 Space/Enter를 지원하며 취소·포커스 이탈·화면 전환에도 비교 상태를 해제한다. 채팅에는 비교·수정 결과 보기 버튼을 두지 않고 적용·취소·재시도 같은 작업 명령만 남긴다.

새 수정안은 실제 PPTX 렌더링과 검증을 마친 뒤 중앙에 표시한다. 적용 전 비교는 기준 장표와 수정안 사이, 적용 후 비교는 직전 확정 상태와 현재 장표 사이에서 동작한다. 적용은 검토한 출력 파일과 미리보기를 재사용한다. 과거 스키마에서 저장된 미리보기 없는 수정안은 기존 적용 경로를 유지한다.

되돌리기는 **현재 편집 세션에서 최대 3단계**다. 여러 장표를 한 번에 적용한 변경은 하나의 단계이며 발표자료 전체를 이전 상태로 복원한다. 복원은 새 확정 리비전을 만들고 기존 파일·장표 버전을 재사용한다. 편집 화면 이탈·프로젝트/발표자료 변경·탭 종료 시 서버의 되돌리기 참조 목록을 삭제한다. 돌아오면 새 세션으로 시작한다. 종료 신호가 누락되면 30분 비활성 만료 후 정리하고 서버 시작·종료 시에도 초기화한다. **확정된 PPT 버전과 파일은 캐시 정리로 삭제하지 않는다.** 다른 방문자의 변경이 개입하면 이전 세션의 되돌리기로 그 변경을 덮어쓰지 않는다.

Studio → 생성·편집 → 우측 **AI와 대화**에서 바로 수정 요청을 입력한다. AI·수정 범위 선택기는 제공하지 않는다. 객체를 선택하면 해당 객체만, 객체 선택이 없으면 현재 장표 전체가 수정 대상이다. 여러 장표를 명시적으로 선택하면 해당 장표 전체를 일괄 수정한다. 현재 대상은 읽기 전용 안내로 표시한다. 메시지와 수정 전후를 검토한 뒤 **수정안 적용**을 누르면 새 PPTX 리비전을 만든다. 제안 도착만으로 원본을 변경하지 않는다. 실패·취소·재시도와 수정안 버리기를 지원한다.

서버가 기준 발표자료의 생성·수정에 사용한 연결을 찾아 현재 활성 LLM 설정 버전을 요청 접수 시 고정한다. Decision 모델은 사용하지 않고 임의의 다른 연결로 자동 대체하지 않는다. 해당 LLM을 사용할 수 없으면 입력을 유지하며 Admin 설정 확인을 안내한다. 장표 전체가 수정 가능해도 요청하지 않은 필드는 모델이 null을 반환해 원본을 그대로 보존한다.

- `features/presentations/slide-chat.tsx`는 Query 기반 메시지 조회·명령, `chat-drafts.ts`는 프로젝트/리비전/슬라이드별 메모리 draft를 소유한다. 공식 shadcn Message/Bubble/Message Scroller와 InputGroup을 사용한다. Enter 전송은 IME 조합을 제외하고 Shift+Enter는 줄바꿈한다.
- Rust `modules/presentations/edits.rs`는 입력·취소·lease·고정 모델 실행, `edit_model.rs`는 `propose_slide_patch` 형식과 허용 필드 검증, SQLite `presentations/edits/`는 접수·체크포인트·조건부 적용을 소유한다.
- 기존 native Provider adapter와 모델 실행 한도/이력을 재사용한다. 이는 제한된 구조화 수정 명령이며 Provider-native 다중 Tool Calling이나 임의 도구 실행 에이전트는 아니다. 메시지는 토큰 스트리밍 대신 영속 작업 조회로 갱신한다.
- 서버는 선택하지 않은 필드·근거 ID를 원본에서 보존한다. 적용 직전 최신 deck version을 검사하고 오래된 수정안은 거부한다. 변경한 SlideSpec만 새 Blob/slide version으로 저장하며 다른 장표의 version은 재사용한다. 출력 PPTX 조립·미리보기·Kordoc 검증은 전체 deck에 수행한다.
- 대화 이력은 공유 프로젝트의 SQLite에 저장된다. draft는 브라우저 메모리만 사용하며 최대 128개 범위를 보관한다. 이전 리비전은 읽기 전용이며 적용이 끝난 최신 리비전에서 계속 수정한다. 패널을 접어도 입력과 선택을 유지한다.

제품은 좌측 장표의 전체 선택·개별 선택 버튼 또는 Ctrl/⌘ 클릭으로 최대 24장을 골라 일괄 수정한다. 객체 탭과 장표 위 선택 영역에서 객체를 선택하고 Ctrl/⌘로 다중 선택한다. 선택 객체가 있으면 그 ID만 수정·삭제할 수 있고 다른 객체는 서버에서 보존한다. 여러 장표를 선택하면 객체 선택은 해제한다.

**객체** 탭에서 PNG/JPEG/WebP 이미지를 등록한 뒤 삽입 요청을 작성하거나, 실제 항목·수치를 입력해 차트 요청을 작성한다. 등록만으로 장표를 변경하지 않는다. 막대·가로 막대·꺾은선·원형 차트, 사각형·타원·텍스트 상자, 이미지 교체/삭제, 위치·크기·회전과 제목/본문 위치를 대화로 수정한다. 이미지의 원본은 보존하고 비율을 유지해 지정된 틀에 맞춘다. 차트에는 편집 가능한 데이터 workbook이 포함된다.

수정안의 실제 장표는 중앙 캔버스에서 장표별로 검토한다. 모든 대상과 미리보기가 준비된 뒤 한 번 적용하며 실패하면 이전 deck은 그대로다. 완료한 장표 수정안을 저장해 재시작·재시도에서 재사용한다. 한 장표당 모델 한 번을 순차 호출하고 완료된 장표의 모델 호출은 반복하지 않는다. 이 영속 작업 상태와 세션 종료 시 삭제하는 되돌리기 캐시는 별개다.

이미지 자르기/보정, 애니메이션·그룹화, 원본 PPTX의 임의 기존 객체 내부 편집과 슬라이드 목록의 포인터 드래그 정렬은 후속 범위다. 캔버스 이동·크기 조절과 장표 메뉴는 실제 제품에 연결되어 있다. 원본 PPTX 장표와 객체의 실제 삽입은 지원한다. 객체 배치는 마우스·터치·방향키·숫자 입력 또는 대화 요청으로 수정한다.

## 레퍼런스 삽입과 대화 수정

참고 자료 탭의 **레퍼런스 넣기**는 공용 파일을 찾고 장표·차트·이미지·도식·표·글의 미리보기를 확인한 뒤 최대 10개를 명시적으로 선택한다. 크게 보기와 선택은 별도 명령이다. 원본 장표는 현재 장표 뒤에 별도 장표로 추가하고, 개별 자료는 현재 장표의 객체로 넣는다. 기존 장표 버전은 재사용하고 변경한 장표만 새 Spec을 갖는다. 전체 결과는 실제 PPTX 렌더링·검사 후 새 리비전으로 저장하며 이전 출력은 유지한다.

삽입한 자료는 같은 탭에서 **사용한 원본 보기**로 정확한 파일 버전/페이지를 연다. 원본이 논리 삭제되어도 확정된 출력과 고정 참조는 보존하며, 새 자료 선택에서는 제거된 원본을 제외한다. PPTX 차트·표·도식은 네이티브 구조를 보존해 PowerPoint에서 편집할 수 있다. PDF 페이지는 이미지이며 PDF 벡터를 편집 객체로 복원하지 않는다.

대화 수정은 서버가 제한적으로 찾은 공용 레퍼런스와 기존 고정 자료만 사용한다. 허용된 reference_id를 선택한 객체 목록/배치에 제안하며 URL·경로·SQL은 실행할 수 없다. 선택한 객체만 위치를 수정하거나 삭제할 수 있고, 선택이 없으면 현재 장표 전체가 기본 범위다. 내부 네이티브 차트의 데이터·개별 하위 도형을 웹에서 직접 조작하는 기능과 범용 다중 도구 자율 에이전트는 별도 범위다. 수정안 작성과 실제 미리보기 준비 단계를 표시하며 최종 적용은 사용자 승인이 필요하다.

## 장표 확인 결과와 부분 렌더링

생성 화면과 AI 수정안에는 실제로 확인한 장수, 최초 생성에서 글자 크기를 맞춘 장수, 확인이 필요한 장표 번호가 표시된다. 글자 넘침·내용 누락은 완료나 수정안 적용을 막는다. 도형·참고 자료 겹침은 의도한 디자인일 수 있으므로 해당 장표를 검토하도록 안내한다. 내부 오류 코드·검사 도구·임의의 전체 진행률은 표시하지 않는다. 상태 갱신은 키보드 초점을 옮기지 않는다.

수정안은 변경된 장표의 파일·미리보기만 새로 만들고 나머지 장표를 재사용한 뒤 전체 PPTX를 조립한다. 동일 본문·제목·배치는 앞서 확인한 글자 크기를 유지한다. 새 글에 맞추기 위해 사용자 모르게 더 줄이지 않으며, 선택하지 않은 객체나 원본 장표의 내부 요소를 재배치하지 않는다. 비교·승인·적용·되돌리기 동작과 이전 리비전은 유지한다.

## 직접 작성과 캔버스 조작

원본 등록 화면의 **빈 장표로 직접 작성** 또는 생성·편집의 **직접 작성** 탭에서 템플릿과 실제 레이아웃을 선택한다. 배경과 마스터를 유지한 빈 PPTX로 시작하며, 없는 원본·가이드·목차·근거나 모델 호출을 만들어 넣지 않는다. 미사용 분석 단계는 완료로 표시하지 않는다.

템플릿 선택은 필수가 아니다. 미선택 시 **기본 디자인**에서 **빈 장표** 또는 **제목과 본문** 배치를 선택하며, 16:9의 편집 가능한 PPTX로 시작한다. 장표 추가에서도 같은 기본 배치를 제공한다. AI 생성은 템플릿 미선택 시 PPT Master 기본 배치를 사용하고 기존 원본·근거 검토 조건을 유지한다. 템플릿을 명시적으로 선택한 경우에만 해당 버전의 실제 레이아웃을 적용하며, 잘못된 템플릿 배치를 기본 디자인으로 조용히 대체하지 않는다.

객체를 끌어 이동하고 모서리로 크기를 바꾼다. Ctrl/Command로 여러 객체를 선택하면 함께 이동한다. 이미지는 비율을 유지하며, 다중 선택의 크기 조절은 단일 객체를 선택한 뒤 수행한다. 방향키와 Shift+방향키로 이동하고 **위치·크기** 입력창으로 드래그 없이 조작할 수 있다. Escape·창 이탈·화면 전환은 미완료 제스처를 취소한다. 포인터 이동 중에는 저장하지 않고 놓을 때 한 번만 요청한다.

원본 전체 미리보기 아래에 배경·객체 PNG를 분리하여 실제 그림을 움직인다. 기존 결과에 분리 이미지가 없거나 캐시가 정리된 경우 전체 미리보기를 유지하고 저장 후 갱신한다. 브라우저에서 원본 SVG나 문서 코드를 실행하지 않는다. PNG 준비의 load/error 관찰은 상호작용이 아니므로 해당 이미지의 Biome 비상호작용 이벤트 경고만 좁게 예외 처리하며, 실제 조작은 별도의 버튼이 소유한다.

텍스트·도형·이미지 추가와 선택 텍스트 수정은 캔버스 도구에서 실행한다. 왼쪽 + 메뉴는 템플릿의 실제 배치를 사용해 장표를 추가하고, 썸네일 우클릭/점 세 개 메뉴는 복제·삭제·위/아래 이동을 제공한다. 최소 한 장, 최대 24장을 유지한다. 저장은 새 리비전을 만들며 완료하기 전까지 이전 장표를 보존한다. 비교·3단계 되돌리기와 공유 버전 충돌 검사도 같은 규칙을 따른다.

빈 장표의 첫 대화 수정은 Admin에 준비된 첫 활성 작성용 LLM을 서버에서 선택하여 고정한다. 적용한 뒤에는 해당 연결을 기준으로 현재 설정 버전을 사용한다. 이미 연결된 모델이 비활성/삭제된 기존 자료에서는 다른 연결로 조용히 전환하지 않는다. 작성용 모델이 없으면 연결 설정을 안내하며 직접 조작은 계속 사용할 수 있다.
